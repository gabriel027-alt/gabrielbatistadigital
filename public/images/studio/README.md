# Ilustrações de estúdio

`day.webp` e `night.webp` são ilustrações originais produzidas com geração de imagem para esta direção visual da Gabriel Batista Digital. A versão diurna foi criada a partir da composição noturna para preservar enquadramento e continuidade entre temas.

Não são fotografias de Gabriel, de funcionários ou de um escritório real. A seção sobre identifica a cena como ilustrativa. Nenhuma imagem, personagem, screenshot ou marca da EvoPixel foi incorporada.

As imagens foram convertidas para WebP com dimensões preservadas. A preferência de tema define o único arquivo pré-carregado para a hero da home.
