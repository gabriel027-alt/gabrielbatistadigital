# Sequência da hero

Nove quadros independentes em WebP, numerados 00–08. Cada pose tem versão de 1280×720 e versão móvel de 768×432. Os dois extremos usam as imagens aprovadas em conversa; os sete intermediários foram gerados a partir delas e ordenados pela continuidade da composição. Não são frames extraídos de uma filmagem ou de um modelo 3D.

O canvas desenha um quadro opaco por atualização: não existe dissolução, mistura de rostos ou interpolação de pixels. Pequenas diferenças entre imagens geradas podem continuar perceptíveis. A sequência é uma aproximação editorial e não uma reconstrução física exata.

O tamanho total dos 18 arquivos é aproximadamente 946 KB. Uma visita carrega apenas a variante apropriada ao tamanho inicial da tela. Movimento reduzido ou economia de dados mantém a abertura estática. A imagem HTML de abertura permanece como fallback sem JavaScript/canvas.
